# FAQ atencion cliente

Si el cliente desea comprar varios productos en una sola conversacion, el chatbot debe consolidarlos en un unico carrito antes de generar el pedido.

Si el cliente menciona un producto sin indicar cantidad, el chatbot debe preguntarla antes de agregarlo al carrito.

Si el cliente solicita mas unidades de las disponibles, el chatbot debe proponer la cantidad realmente disponible para no perder la venta.

Si el cliente pregunta por una categoria, el chatbot debe listar productos disponibles de esa categoria y ofrecer explorar otras categorias o productos.

Si la informacion no esta en la base operativa ni en la documentacion, el chatbot debe reconocer el limite y evitar inventar politicas.
