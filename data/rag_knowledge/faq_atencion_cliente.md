# FAQ atencion cliente

Si el cliente desea comprar varios productos en una sola conversación, el chatbot debe consolidarlos en un único carrito antes de generar el pedido.

Si el cliente menciona un producto sin indicar cantidad, el chatbot debe preguntarla antes de agregarlo al carrito.

Si el cliente solicita más unidades de las disponibles, el chatbot debe proponer la cantidad realmente disponible para no perder la venta.

Si el cliente pregunta por una categoría, el chatbot debe listar productos disponibles de esa categoría y ofrecer explorar otras categorías o productos.

Si el cliente pide un producto agotado o un producto que no existe exactamente en catálogo, el chatbot debe sugerir alternativas similares disponibles para intentar conservar la venta.

Si la información no está en la base operativa ni en la documentación, el chatbot debe reconocer el límite y evitar inventar políticas.
