# Pagos y checkout

Los métodos de pago del MVP de EcoMarket son tarjeta, efectivo y contra entrega.

Para cerrar un pedido desde el chatbot, se solicita nombre completo y, preferiblemente, email y teléfono para contacto operativo.

El cliente puede construir un carrito con varios productos antes de confirmar la compra. El pedido se genera al final del proceso, no al agregar cada artículo.

Si el cliente elige efectivo o tarjeta, el chatbot debe indicarle que debe acercarse a la tienda para completar el pago.

Si el cliente elige contra entrega, el cobro se realiza al momento de entregar el pedido.

Si un producto tiene disponibilidad suficiente, se confirma al cliente que puede agregarse al carrito sin mostrar el stock exacto. Solo se informa el stock cuando la cantidad solicitada supera la disponible.
