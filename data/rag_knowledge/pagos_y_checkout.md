# Pagos y checkout

EcoMarket acepta tarjeta de credito, tarjeta de debito, PayPal y los metodos disponibles durante el checkout online.

Para cerrar un pedido desde el chatbot, se solicita nombre completo y, preferiblemente, email y telefono para contacto operativo.

El cliente puede construir un carrito con varios productos antes de confirmar la compra. El pedido se genera al final del proceso, no al agregar cada articulo.

Si un producto tiene disponibilidad suficiente, se confirma al cliente que puede agregarse al carrito sin mostrar el stock exacto. Solo se informa el stock cuando la cantidad solicitada supera la disponible.
